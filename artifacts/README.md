# Local diagnostics

Tools write screenshots, recordings, serial logs, and validation reports here.
These outputs can contain speech, network names, or local device details and
are excluded from Git. Existing local results are retained during cleanup.

Run checks from the repository root. This directory exists in a fresh clone so
diagnostic tools have an output destination. Older development notes refer to
reports from the original workspace; those reports are local evidence, not
files distributed in this repository.
