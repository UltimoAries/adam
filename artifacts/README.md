# Local diagnostics

Helper scripts under `tools/` (see [`tools/README.md`](../tools/README.md)) write
screenshots, recordings, serial logs, and validation reports here. These outputs
can contain speech, network names, or local device details and are excluded from
Git while this `README.md` keeps the directory present in a fresh clone.

Run checks from the repository root. Historical notes under `docs/` occasionally
mention local validation reports in `artifacts/`; those files are generated local
evidence rather than tracked assets distributed in this repository.
